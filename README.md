# 거던 빌더 프로토타입 0.1

## 실행
- `index.html`을 Chrome, Edge, Firefox 등 최신 브라우저에서 엽니다.
- 정적 페이지라 별도 서버나 설치가 필요하지 않습니다.

## 포함 기능
- 키워드 필터와 검색으로 샘플 인격 선택
- 편성 인원 제한 없는 파티 편성 및 순서 변경
- 편성 키워드 가중치 합산과 집중도 시각화
- 편성 키워드에 따른 샘플 에고 기프트 추천
- 보유 기프트 목록 관리
- 샘플 강화 단계/합성 재료 경로 표시
- 브라우저 localStorage에 빌드 저장/불러오기
- JSON 내보내기/가져오기

## 데이터 확장
- `data/identities.json`: 인격 목록
- `data/gifts.json`: 에고 기프트 목록
- `data/keywords.json`: 키워드 목록

현재 브라우저 데모는 `index.html` 내부에 내장된 데이터 배열을 사용합니다. 초기 프로토타입을 file://로 직접 열어도 작동하게 하려는 선택입니다. 데이터가 커지면 `fetch()`를 쓰는 로컬 서버 방식으로 바꾸거나 빌드 도구를 도입해 `data/*.json`을 불러오도록 전환할 수 있습니다. 데이터 파일의 스키마는 JS 배열과 동일하게 유지하세요.

## 데이터 정확성 주의
현재 포함된 인격 일부와 모든 기프트 이름/효과/레시피는 기능 시연용 샘플입니다. 실제 게임의 공식 명칭, 패시브, 효과 수치, 합성 레시피와 일치한다고 보장하지 않습니다. 실제 서비스용 데이터베이스를 채우기 전 공식/게임 내 자료로 검증하세요.
